## What it does

`main.py` (stdlib only, Python 3.13) writes a single funny line about
office life, 99 characters, to `/output/entry.txt`. The line is fixed,
deterministic, and needs no network: a new intern asks where the fire
exit is, and the manager points at the door marked "career growth".

> The intern asked where the fire exit was, so my manager pointed at the door marked 'career growth'.

## Run it

```sh
python3 main.py
```

## Sparring

Fourteen candidate jokes were drafted and sparred head-to-head against
the published judge brief (setup + turn, universal office trope,
surprise, punchline last, feels new). The winner beat every other
candidate in a round-robin (5-0) and beat the strongest challengers again
in rematches. See [spar-notes.md](spar-notes.md).
